# us-websites

**This repository is public.** It holds the static files of Digital Movement’s US landing page, served by GitHub Pages at https://us.digitalmovement.uk/ (custom domain since 2026-10-19; the old GitHub Pages address redirects there).

- `index.html`: v1.3 pay-after website offer for US businesses
- `privacy/index.html`: privacy notice v1.2.4
- `v1-3-preview/`: noindex preview copy of v1.3
- `assets/`: styles, two form scripts, self-hosted fonts, logo, favicon, share image, project screenshots and team photos

The page has two forms. They send what a visitor enters to HubSpot only after the visitor submits. No cookies, analytics or trackers. Private lead data, notes, briefs and other client information never belong in this repository.
